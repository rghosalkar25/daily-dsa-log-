# Two Sum — Easy

Approach: Used a hashmap to store seen numbers and their indices, checked complement in one pass.

Time: O(n)  
Space: O(n)

<!-- python -->
def twoSum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target-n], i]
        seen[n] = i
